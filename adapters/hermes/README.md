# Hermes adapter

Existing integration entry point: python3 server/send_page.py --help. The default is local export; select transport explicitly when sending. Set AGENT_PAGES_ROOT, AGENT_PAGES_BASE_URL and AGENT_PAGES_ENV (BlueBubbles config path). No running Hermes profile is modified. Native helper sources are in server/native; native delivery requires separate operator installation and remains unverified for this extracted candidate. See docs/security.md.
