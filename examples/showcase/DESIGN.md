# Visual brief — Astra design lead

Set before implementation: one 2700px-wide editorial composition on warm ivory.
Three equal iPhone portrait frames, generous gutters, charcoal typography and sage
accents inherited from the repository renderer. Captions: “Make a plan”, “Choose
with clarity”, “Take the next step”. Synthetic weekend workshop content connects
a plan, a room decision and a working RSVP form. Real mobile web captures at
390 × 844 CSS pixels, device scale 3; no native-app or delivery claim.

Keep renderer styles intact. Frame decoration belongs to the composition only.
Use short content that fits each viewport. Preserve README onboarding and licensing.
Inspect full resolution and 880px / 390px reductions before final approval.
