# Constraints and security

The private API has no application authentication: loopback and tailnet membership are its access boundary. Every permitted tailnet client can read the library. Restrict access with explicit Tailscale ACLs or an authenticated reverse proxy. Never expose port 9133 publicly. Mutation routes require a client header and reject Origin, but headers are not authentication. Protect state and use HTTPS outside loopback.

Pages contain executable JavaScript. Only build trusted Page source: bundling executes server rendering on the host. Live HTML is trusted content. Shared snapshots strip scripts and apply a restrictive CSP; regex transformation is defense in depth, not a general HTML sanitizer. Snapshots are bearer links with expiry/revocation and no identity verification. Avoid sensitive content.

Native iMessage cards require macOS Messages, BlueBubbles private API and an injected helper using unstable Apple private selectors. Permissions, account setup, injection and recovery are operator work; no installer changes macOS permissions, SIP or Apple accounts. Configure AGENT_PAGES_ENV for an explicit BlueBubbles env file; AGENT_PAGES_BALLOON_BUNDLE must name your signed extension balloon identifier. Native delivery is unverified after generic configuration changes. Rich-link fallback loses native extension behavior; HTML/reference attachment fallback is read-only and cannot preserve live form state. Quick Look renders snapshots rather than a live agent connection. Simulator compilation does not establish physical-device delivery support.
